# Design reference images

Loose design artifacts kept for reference. **Nothing in this folder is bundled
into the app** (`pubspec.yaml` declares only `assets/icon/`), and nothing in
`lib/`, the tests or the build configuration reads it.

## `splash_check.png`

| | |
|---|---|
| What | The Roost logo (white house-in-a-pin) on a solid black background |
| Size | 1024 x 1024 px, 8-bit RGB, **no transparency**, about 60 KB |
| Added | 2026-08-11, commit `837944d` ("Add listing intro screen, labeled step progress, redesigned photos step"). It lived in the repository root until it was moved here. |
| Origin | Most likely a visual check made when the splash images were regenerated; `web/splash/img/*.png` changed in the same commit. Nothing else in the repo documents it, so treat this as an inference. |

### How it relates to the real assets

- **Splash screen:** generated by `flutter_native_splash` from
  `assets/icon/roost_logo.png` on `#000000` (see `pubspec.yaml`). This file is
  not an input to that.
- **Launcher icon:** generated by `flutter_launcher_icons` from
  `assets/icon/roost_icon.png` and `assets/icon/roost_icon_foreground.png`.
- **iOS App Store icon:** already exists at
  `ios/Runner/Assets.xcassets/AppIcon.appiconset/Icon-App-1024x1024@1x.png`.
- **Compared with the master logo** (`assets/icon/roost_logo.png`, a
  transparent PNG): this is *not* a pixel copy. With the master flattened onto
  black, about 3% of pixels (roughly 31,000 of 1,048,576) differ by more than
  8 levels. Prefer the master for any new work.

### When it might be useful

- A quick visual reference of the logo on the splash background (white on
  black).
- Marketing or store graphics that need a flat, no-alpha, 1024 x 1024 logo on
  black. Check it still matches the current brand first, because it is a
  slightly different render from the master.
- **Not** suitable as the source for regenerating the splash or icons. Use
  `assets/icon/roost_logo.png`.

### Please don't

- Move it under `assets/icon/`. That folder is declared in `pubspec.yaml`, so
  everything in it is bundled into every build. `docs/` is not bundled.

### Finding its history

```bash
git log --follow -- docs/design/splash_check.png
```
